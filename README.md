# 🎲 The Geek Peek - Full-Stack Redesign Platform

A modern, high-performance Full-Stack web application concept for **The Geek Peek**, a local game store hosting weekly tabletop tournament events for 60+ players. This repository tracks a complete Full-Stack modernization.

## 🛠️ The Technical Stack Blueprint

*   **Frontend Client:** React.js, TypeScript, Vite, Tailwind CSS v4.0, Lucide Iconography
*   **Backend Server:** Node.js, Express.js (Stateless REST API Engine)
*   **Database Layer:** PostgreSQL (Relational inventory, order mapping, and user data models)
